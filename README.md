# Tomoshibi 灯火

*Tomoshibi* is Japanese for "lamplight" — a small light kept burning for someone.

Tomoshibi is a simple, friendly voice companion for older adults, especially those
living with memory loss. There are no screens or menus: press the glowing button,
talk, and Tomoshibi answers warmly — no matter how many times the same question
is asked.

## Features
- **One-button conversation** powered by Claude, with speech recognition and natural TTS
- **Spoken reminders** for medication, meals, visits, and appointments
- **Caregiver mode** so family can add or change events just by talking (or from a phone)
- **Personal context** — knows family names, routines, and today's plans
- **Reliable by design** — auto-starts on boot, recovers from errors, and falls back
  to offline reminders if the internet is down

## Hardware
- Raspberry Pi 5 (4 GB) with RTC battery
- USB speakerphone (e.g., Jabra Speak 410)
- Large momentary push button with LED

> Tomoshibi is a companion, not a medical device. It's meant to support — never
> replace — human care.
