Tomo tries the new network for up to 2 minutes. The setup Wi-Fi turns off while it does, so your phone will disconnect. If it can't get online, Tomo goes back to how it was and the setup Wi-Fi comes back.

To change Wi-Fi, start setup mode on Tomo: hold the button for 10 seconds, let go, then press it once more. Tomo's screen then shows what to do.

Try a pronunciation

Hear a name in Tomo's own voice, try different spellings until it sounds right, then save it. The spelling Tomo shows stays the same; only how it's said changes.
